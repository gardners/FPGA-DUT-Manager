# 0011: Chain link bring-up

Status: Open (phase 3)
Opened: 2026-11-25

Two-ribbon link per ADR 0007. Measure eye/cable length, training, presence detect, enumeration with 1–4 nodes.

## 2026-11-26 status (lead)

Not started. The ADR 0007 pin plan is out of date: the keyboard harnesses now
use rows 10-20 (ADR 0008 amendment 4), and P13 rows 10-13 are proposed for a
second HDMI receiver (0043). Issue 0044 compares doing the cross-board
keyboard and video over Ethernet instead; this issue waits for that decision.
